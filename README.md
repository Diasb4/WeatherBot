# 🌤️ Telegram Weather Bot (Vercel Serverless + Inline Mode)

Красивый, современный Telegram-бот погоды на базе **OpenWeatherMap API**, работающий через **Webhooks на Vercel Serverless Function** с полным исходным кодом в едином индекс-файле.

---

## ✨ Возможности

- 🔍 **Инлайн-режим (Inline Mode):** наберите `@ваш_бот Город` в **любом** чате, канале или группе, чтобы мгновенно увидеть превью с погодой и отправить стильную карточку собеседнику.
- 🎨 **Красивое оформление:**
  - Флаг страны (🇷🇺, 🇺🇸, 🇫🇷, 🇯🇵 и т.д.) по коду локации;
  - Динамические эмодзи состояния погоды (☀️, ⛅, 🌧️, ❄️, ⛈️, 🌫️, 🌙);
  - Температура и «ощущается как» со знаком `+` / `-`;
  - Атмосферное давление в привычных **мм рт. ст.** и гПа;
  - Ветер с указанием скорости, направления компаса (↗️, ↖️, ⬇️) и порывов;
  - Время восхода и заката с расчетом местного времени города;
  - Влажность, облачность и дальность видимости.
- 🔄 **Интерактивные кнопки:**
  - «🔄 Обновить» — обновляет данные прямо в сообщении;
  - «↗️ Поделиться» — быстрый инлайн-шеринг;
  - «📍 На карте» — переход в Google Maps по точным координатам;
  - «📊 OpenWeather» — страница города на OpenWeather.
- 📍 **Поддержка геолокации:** отправьте боту геопозицию через скрепку Telegram 📎 в чате — он сразу определит погоду в этой точке.
- ⚡ **Vercel Serverless & Webhooks:**
  - Мгновенный холодный старт, отсутствие постоянных серверов;
  - При открытии ссылки Vercel в браузере открывается **удобный веб-дашборд** со статусом и кнопкой быстрой регистрации вебхука в 1 клик!

## 🚀 Быстрый старт и развертывание

### Шаг 1. Создайте бота в Telegram
1. Откройте [@BotFather](https://t.me/BotFather) в Telegram.
2. Отправьте `/newbot`, укажите имя и юзернейм (например, `MyCoolWeatherBot`).
3. Скопируйте полученный **HTTP API Token** (`BOT_TOKEN`).

### Шаг 2. Включите Инлайн-режим (ОБЯЗАТЕЛЬНО!)
1. В [@BotFather](https://t.me/BotFather) отправьте команду `/setinline`.
2. Выберите вашего созданного бота.
3. Введите текст-подсказку (плейсхолдер), например: `Погода в городе...`
4. *Готово! Теперь бот поддерживает вызов через `@ваш_бот` в любых диалогах.*

---

### Шаг 3. Деплой на Vercel

#### Вариант A. Через GitHub (рекомендуется):
1. Загрузите файлы этого проекта в свой репозиторий на GitHub.
2. Перейдите на [vercel.com](https://vercel.com) и нажмите **Add New... -> Project**.
3. Импортируйте ваш репозиторий.
4. В разделе **Environment Variables** добавьте:
   - `BOT_TOKEN` — токен от `@BotFather`
   - `OPENWEATHER_API_KEY` — ваш ключ: `5fc94082b0bd5d73c10e14c959ac190a` *(уже встроен по умолчанию, но можно переопределить)*
5. Нажмите **Deploy**.

#### Вариант B. Через Vercel CLI:
```bash
npm install -g vercel
vercel
```

---

### Шаг 4. Привязка Webhook (2 простых способа)

После завершения деплоя Vercel выдаст вам домен, например: `https://my-weather-bot.vercel.app`.

#### Способ 1: В 1 клик через веб-дашборд (самый простой)
1. Просто откройте ваш домен Vercel в браузере: `https://my-weather-bot.vercel.app`
2. На открывшейся странице нажмите кнопку **«🔗 Зарегистрировать Webhook в Telegram»**.
3. Вы увидите зеленый ответ от Telegram: `{"ok": true, "result": true, "description": "Webhook was set"}`.

#### Способ 2: Вручную через браузер или curl
Откройте ссылку в браузере (заменив `ВАШ_ТОКЕН` и `ВАШ_ДОМЕН_VERCEL`):
```text
https://api.telegram.org/botВАШ_ТОКЕН/setWebhook?url=https://ВАШ_ДОМЕН_VERCEL/api
```

## 💻 Локальный запуск для разработки

```bash
# Установка зависимостей
npm install

# Запуск локального сервера (порт 3000)
node api/index.js
```
Откройте `http://localhost:3000` в браузере для просмотра веб-дашборда.

## 📱 Примеры использования

| Способ | Что набрать | Результат |
| :--- | :--- | :--- |
